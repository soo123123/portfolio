# 👋 Intro

컴퓨터소프트웨어를 전공하며 **Backend를 중심으로 소프트웨어 개발 경험을 쌓고 있는 개발자**입니다.

Spring Boot를 활용한 서버 개발과 React 기반 웹 서비스 구현을 경험했으며,
서버와 데이터베이스, 클라이언트 간의 구조를 이해하고
서비스를 직접 설계하고 구현하는 과정에 관심을 가지고 있습니다.

현재는 백엔드 개발 역량을 기반으로 **AI 기술을 실제 서비스에 적용하는 개발자**를 목표로
AI 기반 프로젝트와 개인 개발을 진행하고 있습니다.

문제를 단순히 기능으로 구현하는 것보다
**서비스의 구조와 각 구성 요소의 역할을 고민하고 설계하는 과정**을 중요하게 생각합니다.

## 4. 📈 투자 포트폴리오 리밸런싱 AI Agent

> **AI Agent 기반 투자 포트폴리오 분석 및 자동 리밸런싱 시스템**

- **분야** : Backend / AI Agent / Financial Technology
- **Status** : In Progress

### 개발 목표

투자자의 포트폴리오와 시장 데이터를 바탕으로
현재 포트폴리오의 상태를 분석하고,
리밸런싱이 필요한 상황을 판단하여
**실제 투자 주문까지 수행할 수 있는 AI Agent 시스템**을 개발하고 있습니다.

단순한 투자 정보 제공을 넘어
데이터 수집부터 포트폴리오 분석, 리밸런싱 전략 수립,
주문 실행까지 하나의 Agent Workflow로 연결하는 것을 목표로 합니다.

### 주요 개발 내용

- 투자 포트폴리오 및 보유 자산 데이터 관리
- 시장 및 투자 관련 외부 데이터 수집
- 포트폴리오 구성 및 자산별 비중 분석
- 현재 포트폴리오와 목표 비중 비교
- AI Agent 기반 리밸런싱 필요성 및 전략 분석
- 리밸런싱 대상 및 주문 수량 결정
- 증권사 API를 이용한 실제 투자 주문 연동
- 분석 → 의사결정 → 주문 실행으로 이어지는 Agent Workflow 설계
- 주문 결과 및 포트폴리오 상태 업데이트

현재 Agent의 역할과 전체 시스템 구조를 설계하고
포트폴리오 분석 및 리밸런싱 기능부터 단계적으로 구현하고 있습니다.
최종적으로는 **Agent가 포트폴리오를 분석하고 리밸런싱을 결정한 뒤
실제 주문까지 수행하는 시스템**을 목표로 개발하고 있습니다.
